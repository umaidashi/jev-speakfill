jev-speakfill

設定すると Jev をここ経由で呼ぶ（API キーはサーバ側）。空なら上のキーで直接呼ぶ（BYOK）。サーバは発話ごとのトレースを logs/traces.jsonl に書く。

core/config.ts の SpeakfillConfig の一部を JSON で。空なら日本語一般の最小設定。サーバ経由のときはサーバの設定に重ねて送る。例: リポジトリの examples/web-app/speakfill.config.json（商品登録向け）。

キーは chrome.storage.local にのみ保存され、拡張の service worker からしか使われません。ページ側のスクリプトには渡りません。
